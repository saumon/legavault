# LegaVault 🛡️

**Your Transferable Digital Vault**

LegaVault is a showcase website for a secure digital vault solution, designed to protect your digital assets and ensure their transmission to your loved ones.

## 🌟 About

This project is a modern, responsive landing page presenting LegaVault's services:
- Secure centralization of access and documents.
- Structured transmission procedure (digital inheritance).
- Intelligent inventory of digital assets.

## 🚀 Website Features

- **Premium Design**: Dark Mode interface with glassmorphism effects and modern gradients.
- **Responsive**: Adapted for mobile, tablet, and desktop.
- **Animations**: Scroll-triggered appearances and smooth interactions.
- **Navigation**: Mobile menu and smooth scrolling between sections.

## 🛠️ Technologies

- **HTML5**: Semantic structure.
- **CSS3**: CSS Variables, Flexbox, Grid, Animations (no framework).
- **JavaScript**: Vanilla JS for the menu and scroll effects.

## 📦 Installation & Usage

### Locally
Simply clone this repository and open the `index.html` file in your browser. No server installation or dependencies are required.

```bash
git clone https://github.com/your-username/legavault.git
cd legavault
# Open index.html
```

### Hosting (GitHub Pages)
This site is designed to be easily hosted on [GitHub Pages](https://pages.github.com/).
1. Push the code to a GitHub repository.
2. Go to **Settings** > **Pages**.
3. Select the `main` branch and the `/root` folder.
4. Your site will be accessible at `https://your-username.github.io/legavault/`.
